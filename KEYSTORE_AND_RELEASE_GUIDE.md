# Arrow City - Release & Keystore Setup Guide

**Package / Application ID**: `com.mitsara.arrowcity`  
**Current Release**: `Beta v1.0.0` (Version Code: `1`)

---

## 1. Generating Keystore & Base64 String for GitHub Secrets

To enable automated release builds via GitHub Actions, generate a dedicated release keystore and convert it to Base64:

### Step 1: Generate Release Keystore
```bash
keytool -genkey -v -keystore release.jks \
  -keyalg RSA \
  -keysize 2048 \
  -validity 10000 \
  -alias upload
```

### Step 2: Convert Keystore to Base64 String
**On Linux / macOS:**
```bash
base64 -i release.jks | tr -d '\n' > keystore_base64.txt
```

**On Windows (PowerShell):**
```powershell
[Convert]::ToBase64String([IO.File]::ReadAllBytes("release.jks")) | Out-File -Encoding ASCII keystore_base64.txt
```

## 2. Configuring GitHub Repository Secrets

In your GitHub repository, go to **Settings > Secrets and variables > Actions** and add the following repository secrets:

| Secret Name | Value | Description |
|---|---|---|
| `KEYSTORE_BASE64` | `[Base64 string from keystore_base64.txt]` | Encoded JKS keystore file |
| `STORE_PASSWORD` | `YourKeystorePassword` | Keystore password |
| `KEY_PASSWORD` | `YourKeyPassword` | Key alias password |
| `KEY_ALIAS` | `upload` | Alias specified during generation |

## 3. GitHub Actions Workflows

This repository contains ready-to-run GitHub Actions pipelines:

1. **`ci.yml` (CI Pipeline)**:
   - Triggers on every push & pull request.
   - Executes JVM Robolectric tests and unit suites (`./gradlew testDebugUnitTest`).

2. **`debug-build.yml` (Debug APK Build)**:
   - Automatically builds `ArrowCity-debug-apk` on push to `main` and manual dispatch.
   - Uploads APK artifact for immediate testing.

3. **`release-build.yml` (Google Play Beta Release)**:
   - Triggers on tag pushes (`git push origin v1.0.0`) or manual workflow dispatch.
   - Automatically decodes `KEYSTORE_BASE64`, signs with your credentials, compiles **Google Play Bundle (`.aab`)** and standalone **Release APK (`.apk`)**, and publishes a GitHub Pre-Release with attached binaries.

4. **`website.yml` (GitHub Pages Landing Page)**:
   - Deploys the landing page and privacy policy from `/website` to GitHub Pages.

## 4. Version Control & Tagging Workflow

To release a new Beta version:

```bash
# 1. Update versionName and versionCode in app/build.gradle.kts if needed
# 2. Commit and push changes
git commit -am "chore(release): prepare Arrow City Beta v1.0.0"
git push origin main

# 3. Create and push a version tag to trigger automated release
git tag v1.0.0
git push origin v1.0.0
```

## 5. Google Play Console Beta Setup

1. Open **Google Play Console** > **Create App**.
2. **App Name**: `Arrow City`
3. **Default Language**: `English (US)`
4. **App Type**: `Game` > `Free`
5. Navigate to **Testing > Closed testing** or **Open testing (Beta)**.
6. Create a new release and upload the `.aab` generated by the `release-build.yml` GitHub action.
7. Fill in the Store Listing:
   - **Short description**: *Navigate city maze grids and slide arrows to freedom with zero ads.*
   - **Category**: *Puzzle / Casual / Brain Teaser*
   - **Privacy Policy URL**: *https://<your-github-username>.github.io/arrowcity/#privacy*
